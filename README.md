# Cruvio

**Social discovery and real-world plans**

Cruvio is a mobile social-discovery app for people who want to meet through small, trusted crews and shared activities. It helps people discover compatible connections and move toward real plans.

## Project scope

- Flutter mobile app and companion web experience
- Crews, plans, events, and messaging
- Discovery with organizer and participation controls

**Technology:** Flutter and Dart, Supabase, web APIs.
